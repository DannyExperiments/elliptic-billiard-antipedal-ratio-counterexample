# Canonical public-safe claim layer

This directory fixes the claim boundary for local repository staging.

- `CANONICAL_CLAIM.md` states the exact supporting-line theorem and the exact
  `N=8` domain certificate.
- `DEPENDENCY_MAP.md` records which conclusions use central symmetry, finite
  line intersections, or the algebraic witness.
- `SCOPE_LIMITATIONS.md` lists interpretations and extensions that are not
  established.

These summaries do not replace the selected proof artifact, the exact
certificate, or an independent replay. Those public artifacts remain release
gates and are deliberately absent from this staging tree.
