# Public-safe audit layer

Only sanitized summaries are stored here. Raw model returns, prompts,
browser receipts, private evidence packets, third-party source archives, and
unrestricted search logs are excluded.

The summaries preserve four separate questions:

1. Is the qualified mathematics valid?
2. What exact source statement is being answered?
3. What prior art limits the novelty language?
4. Which implications follow, and which do not?

An audit summary is evidence about a gate; it is not peer review, formal
verification, or an immutable release.
