# Contributing

Contributions may address:

- an exact mathematical objection with the first invalid inference identified;
- a source-faithful prior-art citation;
- an independent exact verifier;
- a scope-matched formalization without placeholders; or
- an editorial repair that preserves the canonical claim.

Keep mathematical validity, priority, computation, formalization, and release
status separate. Do not submit raw model transcripts, private receipts,
personal data, credentials, screenshots, or third-party source PDFs/images.

Every proposed public file must be added to `PUBLIC_ALLOWLIST.txt`, pass the
privacy/rights scan, and receive a regenerated manifest and checksum ledger.
