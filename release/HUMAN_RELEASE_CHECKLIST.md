# Human release checklist

No unchecked item is authorization by implication.

- [x] Authorship convention: `DannyExperiments`, no affiliation.
- [x] Rights convention: all rights reserved; no repository-wide reuse license.
- [ ] Final manuscript title and preferred citation approved.
- [ ] AI disclosure approved for publication.
- [ ] Canonical public proof and exact evidence approved.
- [ ] Partial-Lean wording and artifact inclusion approved, or omission chosen.
- [ ] Public repository visibility approved.
- [ ] Immutable version/tag/release approved.
- [ ] DOI metadata and deposit approved.
- [ ] External notice or problem-page comment approved.
